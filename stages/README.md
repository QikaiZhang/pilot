# stages · 阶段实训文档

本目录存放**本次仓库的实际训练产物**，与 `docs/` 中的开发规格分离：

- `docs/build/` —— 当前项目仍需遵守的开发、架构、API、测试和阶段规格（施工）。
- `docs/review/`、`docs/history/` —— 复盘/面试与训练变更记录。
- `stages/` —— 每个阶段实际完成的设计、代码沉淀、面试整理与验收记录。

> 约定：每阶段一个子目录 `stage-XX/`；阶段完成时更新本目录的 `CHANGELOG.md` 与 `THOUGHT.md`。开发规格维护在 `docs/build/`，实际训练记录维护在本目录。
