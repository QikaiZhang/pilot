# stages · 阶段实训文档

本目录存放**我们的分阶段实训产物**，与 `docs/`（原始课程资料）分离：

- `docs/` —— 飞书 Pilot 课件整理的原生资料，保持不动，作为契约与参考。
- `stages/` —— 每个阶段的设计、代码沉淀、面试整理与验收记录（按 skill 的增量分支训练流程产出）。

> 约定：每阶段一个子目录 `stage-XX/`；阶段完成时更新本目录的 `CHANGELOG.md` 与 `THOUGHT.md`；`docs/` 只读不改。
