# review · 复盘与面试

本目录放**学习者后续要用的复盘和面试材料**，与 `docs/build/`（施工规格）、`docs/history/`（训练变更记录）分开。

## 目录

| 路径 | 内容 |
| --- | --- |
| [THOUGHT.md](THOUGHT.md) | 设计复盘与评分记录 |
| [interview](interview/README.md) | 面试沉淀、2 分钟项目介绍、口述训练 |
| [interview/thought-questions.md](interview/thought-questions.md) | 分组思考题 |

## 使用规则

- 每完成一个阶段：运行测试、回答复盘问题，并把「设计取舍 + 失败路径 + 测试证据」沉淀到 `THOUGHT.md` 或 `interview/`。
- 阶段验收前：按 [口述训练规则](interview/README.md) 回答数据流、字段选择、模块边界、失败路径、取舍与后续优化，回答必须对应本仓库真实代码和测试。
