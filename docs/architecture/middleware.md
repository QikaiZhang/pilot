# 中间件与可观测性

## 中间件是什么

中间件位于请求入口和业务处理之间，为多个业务提供通用能力，例如鉴权、超时、日志、指标、Trace、限流。Redis、MySQL、ES 是被应用依赖的基础设施；而 HTTP 中间件是应用内的拦截器。二者都常被称为“中间件”是因为它们位于业务和外部系统之间、提供通用能力，但层次不同：一个是独立服务，一个是进程内代码。

## 请求生命周期

```text
请求
  -> 提取/创建 Trace-ID，记录入口，Inflight +1
  -> next：Controller -> Agent -> Tool
  -> 记录状态码、耗时和错误，Inflight -1
  -> 异步上报 Metrics/Trace/Log，返回带 Trace-ID 的响应
```

## 学习重点

- `next` 之前适合做校验、计时器和上下文注入；`next` 之后适合记录结果、收尾和上报。
- 指标标签必须有限且稳定，不能把用户输入、完整 URL 或错误堆栈直接作为高基数标签。
- panic、context cancel 和上报失败都要有边界，不得影响正常资源回收。
