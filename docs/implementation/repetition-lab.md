# 重复逻辑练习台

原则：相同模式不重复劳动，但每种模式至少亲手完成一个完整例子，并能解释后续为什么可以复用。

| 重复类型 | 第一个必须手写 | 第二个练习 | 后续处理 |
| --- | --- | --- | --- |
| 配置 | 一个字段的默认值、环境变量替换和校验 | 一个非法配置测试 | 其余字段按模板复用 |
| Controller | 同步 Chat 的绑定、校验、错误映射 | 知识搜索接口 | 其他接口只改业务参数 |
| Repository | MySQL 历史查询 | Redis 记忆读取 | ES CRUD 使用同一边界 |
| Redis 记忆 | 窗口裁剪、TTL、顺序 | 分片清理 | 其他 key 操作复用封装 |
| ES/RAG | BM25 与向量结果合并去重 | 空召回和超时回退 | 其他索引操作复用查询模板 |
| Agent Tool | 知识检索工具 | 健康检查工具 | 其他工具复用参数/错误协议 |
| 中间件 | 请求耗时和状态码 | API Key 或限流二选一 | CORS/恢复中间件阅读后复用 |
| SSE | 分片循环和 `[DONE]` | 客户端取消 | 其他流式接口复用协议 |
| 测试 | 一个纯函数单测 | 一个 HTTP 契约测试 | 重复 CRUD 使用表驱动模板 |
| E2E | 知识上传 -> 搜索 | Chat -> 历史 -> 观测 | 其他检查复用同一测试夹具 |

每次手写后都回答：输入是什么、状态如何变化、失败怎么处理、为什么放在这一层、如果并发或数据量扩大哪里会出问题。

AI 可以生成 DTO、路由注册、Compose、客户端初始化和重复测试样板；窗口顺序、RRF 合并、SSE 取消、限流并发和 Agent 停止条件必须自己完成。
