# 项目训练契约

这份文档是学习入口。源码只用于校准设计，不要求学习者阅读源码来理解项目。

## 目标

完成一个可运行的 Go AI 运维助手，依次掌握：配置与启动、HTTP/SSE、Redis 短期记忆、MySQL 历史、ES/RAG、Agent/Tool、中间件、可观测性、测试和部署。

## 非目标

- 不一开始拆成多个微服务。
- 不手写十几个相似 Controller、Repository 或 Tool。
- 不把八股答案当成实现，所有结论必须对应一条数据流或一次故障演练。

## 完成项目的方式

每个阶段只依赖本目录文档：

1. 阅读本阶段目标和概念。
2. 先提交字段、接口、数据流和失败路径设计。
3. 按“代表样例”手写一部分重复逻辑。
4. 其余重复样板由 AI 生成，自己 Review 和修改。
5. 运行阶段测试，回答复盘问题，记录到 `docs/THOUGHT.md`。

## 当前推荐路线

- 路线 A：AI 提供骨架和测试，S 级核心逻辑留给学习者完成。
- 每种重复逻辑至少手写一个完整例子；第二个例子用于比较，第三个以后允许复用。
- 第一条完整链路优先：聊天请求 -> 记忆 -> Agent -> 响应 -> 历史 -> 观测。
