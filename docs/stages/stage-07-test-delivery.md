# Stage 07：测试、Compose 与交付

## 测试顺序

1. 纯函数单测：窗口裁剪、分数合并、错误映射。
2. Repository 集成测试：MySQL/Redis/ES 使用隔离测试数据。
3. HTTP 测试：同步、SSE、超时、取消、鉴权边界。
4. 端到端测试：聊天 -> 检索 -> Agent -> 观测 -> 历史。
5. Compose 冒烟测试：从空环境启动并运行健康检查。

## 故障演练

- Redis 延迟或不可用。
- ES 查询超时或索引不存在。
- LLM 返回格式错误。
- 客户端中断 SSE。
- MySQL 写入失败但主响应已经生成。

## 验收

- 关键链路有可重复测试，不只依赖手工点击。
- 每个故障都有日志、Trace-ID 和可解释的恢复策略。
